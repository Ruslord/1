# HOI4 готовый шаблон страны: Новая Россия (NWR)

В репозитории подготовлен набор файлов мода для Hearts of Iron IV:
- новая страна `NWR`;
- 5 фокусов по 35 дней;
- 2 нацдуха;
- ивент;
- решения;
- OOB (базовый стартовый состав армии);
- русская локализация.

## Установка
1. Скопируйте папку `hoi4_mod` в вашу папку модов HOI4 (обычно `Documents/Paradox Interactive/Hearts of Iron IV/mod/`).
2. Создайте рядом файл `hoi4_mod.mod` с содержимым из `descriptor.mod` (или используйте лаунчер для создания обертки).
3. Включите мод в лаунчере.

## Важно
Этот пакет является стартовым шаблоном. Для полноценного старта страны на карте в 1936/1939 обычно дополнительно настраивают владение штатами (state history), дипломатию и расстановку войск под вашу конкретную карту/сценарий.
